  Instructions for Running Backend & Frontend Locally

PROJECT OVERVIEW:
- Backend: FastAPI (Python) + Pure NumPy Dynamic Programming RL Solvers + WebSockets
- Frontend: React + Vite + Vanilla CSS Bento Laboratory

--------------------------------------------------------------------------------
PREREQUISITES:
--------------------------------------------------------------------------------
1. Python 3.8+ (Python 3.11 recommended)
2. Node.js (v18+) & npm

--------------------------------------------------------------------------------
OPTION A: STANDARD RUN (2 TERMINAL WINDOWS)
--------------------------------------------------------------------------------

[TERMINAL 1: BACKEND SERVER]
1. Open a terminal / PowerShell window and navigate to the backend directory:
   cd backend

2. (Optional, if packages not already installed):
   pip install -r requirements.txt

3. Start the FastAPI backend server:
   python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload

   --> Backend runs at: http://127.0.0.1:8000
   --> Interactive API Documentation (Swagger): http://127.0.0.1:8000/docs
   --> WebSocket Telemetry Stream: ws://127.0.0.1:8000/ws/simulation


[TERMINAL 2: FRONTEND DEV SERVER]
1. Open a SECOND terminal / PowerShell window and navigate to the frontend directory:
   cd frontend

2. (Optional, if node_modules not yet installed):
   npm install

3. Start the Vite development server:
   npm run dev

   --> Frontend runs at: http://localhost:5173
   --> Open your web browser and go to: http://localhost:5173

================================================================================
OPTION B: ONE-LINE POWERSHELL COMMANDS
================================================================================

To launch both from a single PowerShell window, you can run:

Start-Process powershell -ArgumentList "-NoExit", "-Command", "cd backend; python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload"
Start-Process powershell -ArgumentList "-NoExit", "-Command", "cd frontend; npm run dev"

Or simply double click: run.bat

================================================================================
HOW THE SYSTEM CONNECTS
================================================================================
1. The frontend on http://localhost:5173 automatically connects to the backend
   at http://127.0.0.1:8000.
2. In the "Simulation" tab, a live WebSocket connects to ws://127.0.0.1:8000/ws/simulation
   to stream real-time elevator positions and RL decision logs.
3. If the backend is stopped, the frontend automatically falls back to an
   in-browser simulation engine with 0 disruption.
4. Clicking the "CONFIG" button in the top header lets you change building
   parameters (floors, elevators, algorithm) at runtime and re-train the RL policy.

================================================================================
AVAILABLE REST API ENDPOINTS:
================================================================================
- GET  /health            : Health check & active algorithm status
- POST /api/configure     : Set building parameters & auto-train RL policy
- GET  /api/state         : Current elevator positions, calls, and metrics
- GET  /api/policy        : Policy convergence stats, Bellman error, and history
- POST /api/simulation    : Controls (play, pause, step, reset, surge)
- POST /api/call          : Manual floor call dispatcher
- GET  /api/audit         : Complete decision audit trail records
- POST /api/experiment    : Benchmark comparison vs heuristic baselines
- GET  /api/regime        : Current & available traffic regimes
- POST /api/regime        : Live switch traffic regime (morning, evening, lunch, etc.)
- GET  /api/bellman       : Live Bellman equation components, V*(s), and top Q-values
- WS   /ws/simulation     : Real-time telemetry stream (including load & bypass telemetry)
